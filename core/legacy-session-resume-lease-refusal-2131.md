# Typed refusal for resuming a chat under a live lease

Patch **2082**.

## Behavior

- `session.resume` on a not-yet-adopted local chat runs legacy adoption. If another writer holds a live turn lease, the refusal is `runtime_coordination_required`; if a compression lock holds it, `session_busy` (field `compression`).
- Backstop: any session dispatcher call that still lets a mutation-guard refusal escape answers wire code 4001 with the busy refusal data and logs one WARNING "untranslated mutation guard refusal", so the missed caller is visible. Previously these escaped as -32603 internal error.

## How it works

`bind_legacy_target` now imports `MUTATION_GUARD_REFUSALS` and `busy_refusal` and translates the exceptions raised by `require_idle` at the call. `AuthorityConnection.dispatch` gains an `except MUTATION_GUARD_REFUSALS` arm (the earlier local import in `mutate` is removed in favour of the module import).

## Code

- `hermes_state_local_migration.py`: `bind_legacy_target`.
- `gateway/session_controls.py`: `AuthorityConnection.dispatch`.

## Tests

**Source regression coverage; not rerun in this documentation pass.** `tests/gateway/test_legacy_adoption_turn_lease.py`: resume under a live turn lease is a typed refusal; under a compression lock is session_busy; dispatcher turns an untranslated guard refusal into busy and warns. Only the gateway session dispatcher path is covered; other transports are untested.

## Applying

Apply ordinal(s) 2082 as part of the snapshot-aware full replay described in [README](README.md), in published order, not as independent patches: later patches in the series edit the same files, and the replay plan decides which are carried verbatim and which are re-bridged. Note the source commit also added five small profile-fixture directories (`default/`, `fixture/`, `owned/`, `p/`, `target/`, each with a SOUL file and a hooks cache JSON) at the repository root, evidently generated by a test run. They are incidental artifacts: carry them verbatim for byte-exact replay, but a fresh reimplementation does not need them. No claim is made here about live rollout; this page documents source behaviour only.

## Gotchas

The backstop hides the type of an unexpected guard error from the client (it reads as busy), so the WARNING is the signal to fix the caller. Related: [turn-lease-busy-release.md](turn-lease-busy-release.md).

## Could this be a plugin?

No. It is session-store migration and wire dispatch code.
