# Adopting finite native-proof slices

Apply an explicitly returned parent protocol proposal to actual disk bytes and re-pin every real consumer before treating it as assembled. An old parent intentionally rejecting a new child's protocol is not integration acceptance. Test the disk loader and byte-pinned manifest, not only an in-memory assembly or mocked loader. Transparently separate legacy transport/profile doubles from current finite-profile proof; update causal-baseline expectations without losing direct exit-code-versus-exec-errno coverage.

When a cold no-spawn FD-count regression reproduces on both old and adopted source, capture descriptor readlink snapshots before imports, after each relevant import and across warmed repeated cleanup paths. A cold ctypes import may retain a descriptor to the Python executable on a particular Linux runtime; that observation does not identify libffi ownership, prove harmlessness or permit widening a strict child census. Separate observed runtime-owned cold initialization from accumulating owned listener/pipe leaks.

Keep exact prelaunch executable-byte coverage complete, including copied control executables. Read-only hash/mode/UUID metadata can close a missing pathname-byte pin but not loaded-image or copy-to-exec custody: copying a denied fixture before source verification leaves its copied bytes unbound. For cooperative controller cancellation, inherit only a validated nonblocking read-only pipe endpoint into every reporter and reexec image; include it in the exact FD census. Write one byte then close the controller writer so EOF broadcasts after another reader consumes the byte. Latch data, EOF, read error and owner loss, and invalidate parent success when cancellation races final validation. Reserve ordered inner-child cleanup, outer-reporter cleanup, main exit and parent collection inside the original absolute cap; killing an owner at its work cutoff can orphan the children it is still cleaning up. Test actual finite composition and endpoint write/close failures with real signals forbidden. These cooperative stages do not preempt native RPC or establish aggregate-tree enforcement.

Bind import coverage to the same immutable child-source bytes that the parent hash-checks and executes, not a sibling-path reread. AST literal-import coverage detects drift but does not prove dynamic or target-platform transitive closure. A missing source/extension leaf does not prove a builtin is registered; positive PyInit exports strengthen evidence but do not establish PyImport_Inittab registration or successful imports. Keep the actual historical byte verifier in the assembled path and test that valid bytes reach it while appended uncovered imports refuse first.

For a reviewed one-shot native diagnostic, use a fixed absolute durable reservation independent of copied source locations, canonical direct-child scratch with a bounded basename, and build/input checks before consumption. Deduct preparation and reservation fsync from the original monotonic cap. Stage files through bounded transfers when archive extraction is refused; never wrap the refused operation. Use an independently reviewed file launcher that hashes exact sources and fsyncs an exclusive bounded started/result journal before calling the driver. A returned report with empty records and early exit is a nonqualifying diagnostic failure, not native enforcement. Preserve the consumed reservation and unknown descendants, read back exact result bytes/hashes, and do not retry automatically. If multiple pre-protocol guards share one exit code, stop attribution at that ambiguity; add bounded stage receipts in source rather than guessing which target guard failed.

Do not call a manifest's successful byte verifier native admission. Preserve unresolved shared-cache, target imports, launchd domains, enforced resource budgets and exact-owned-descendant cleanup separately; a cooperative timeout with unknown survivors is not a whole-lineage resource fence.
