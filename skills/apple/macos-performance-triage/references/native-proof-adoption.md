# Adopting finite native-proof slices

Apply an explicitly returned parent protocol proposal to actual disk bytes and re-pin every real consumer before treating it as assembled. An old parent intentionally rejecting a new child's protocol is not integration acceptance. Test the disk loader and byte-pinned manifest, not only an in-memory assembly or mocked loader. Transparently separate legacy transport/profile doubles from current finite-profile proof; update causal-baseline expectations without losing direct exit-code-versus-exec-errno coverage.

When a cold no-spawn FD-count regression reproduces on both old and adopted source, capture descriptor readlink snapshots before imports, after each relevant import and across warmed repeated cleanup paths. A cold ctypes import may retain a descriptor to the Python executable on a particular Linux runtime; that observation does not identify libffi ownership, prove harmlessness or permit widening a strict child census. Separate observed runtime-owned cold initialization from accumulating owned listener/pipe leaks.

Keep exact prelaunch executable-byte coverage complete, including copied control executables. Read-only hash/mode/UUID metadata can close a missing pathname-byte pin but not loaded-image or copy-to-exec custody: copying a denied fixture before source verification leaves its copied bytes unbound. Do not call a manifest's successful byte verifier native admission. Preserve unresolved shared-cache, target imports, launchd domains, enforced resource budgets and exact-owned-descendant cleanup separately; a cooperative timeout with unknown survivors is not a whole-lineage resource fence.
