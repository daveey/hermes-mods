# Performance acceptance convergence

Keep publication, natural deployment/retirement eligibility, peer diagnostic custody, causal attribution and final qualified measurement as separate manifest states. A component speedup, disabled-capture window or transient-thread CPU lower bound cannot close whole-unit or enabled-capture acceptance.

Reconcile terminal CI once, then advance the earliest unmet state. Do available worker-only causal work while live custody is unavailable rather than repeatedly parking to reproduce the history.

Qualify replay configuration/cache presence before selecting an optimization: an empty private home can create a hot path absent in production. Keep local-component-only results explicitly separate from production parity and live CPU savings.

Preserve thresholds, source fences, existing spend authority and original acceptance when replanning. Distinguish task ordinal/run labels from authoritative counted spend. A replan is not a budget renewal or diagnostic-slot approval.
