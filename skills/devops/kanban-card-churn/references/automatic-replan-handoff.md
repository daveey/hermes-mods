Put the actionable plan in the prerequisite's completion **summary**, not only metadata or an artifact: the home auto-replan applier reads latest_summary (falling back to result), then appends it to the original body and comment before resumption, preserving acceptance. Verify the installed behavior when needed; do not invoke internal DB writers yourself.

Record and read back a supported original-card comment before ending. If operator preflight reports the target is local, use kanban_comment rather than routing around custody. Distinguish that verified comment from the later automatic body append; do not claim the latter before readback. Keep original acceptance and owner mandates unchanged.

Before retaining a dependency on a multi-purpose owner, re-read its newest delivered sub-scope receipt and remaining acceptance: a repaired shipping helper can be installed while the same owner stays open for an unrelated multi-day audit. Ask the existing creator to reassess only that dependency through supported custody; do not complete the owner early, unlink foreign edges yourself or wait for its unrelated audit. Reuse the existing repair/landing owners and make the consumer wait for a landed-SHA/terminal-CI predicate rather than every acknowledgement or progress comment.

A deployment receipt is not independent installed-runtime behavior proof; make that the remaining finite closeout.

Before repeating an approved decomposition, read every already-created continuation's current terminal state and portable handoff. When all slices are done but their foreign-home prerequisite links were never installed, preserve the original integration owner, request only supported home graph repair, and make the next gate exact-commit composition rather than another create or producer wait. For evidence-gated qualification replans, classify run outcomes separately as natural-evidence waits, real defect corrections, independent review/landing, concurrent-build resets and lost probe custody; a run-count trigger is not an implementation-failure count. Keep independent variant cutoffs and fixed backstops intact; require current live probe-host readback on any later rearm, not merely a successful manual predicate invocation.

Distinguish productive continuations from repeated failed attempts before splitting work.
