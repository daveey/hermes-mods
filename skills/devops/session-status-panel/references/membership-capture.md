# Owner-scoped reconciliation captures

Capture complete membership inputs rather than filtering only previously known IDs: replica arrivals/removals, ledger-only obligations/receipts and canonical compression aliases all invalidate. Include alias/re-home creation identity; reused IDs in other chats must not churn the key.

Keep source-mode selection explicit: the legacy replica/ledger path does not cover `links_reader=replica` chat-link shadows, so an unsupported mode must return unknown. Compare unknown as changed even for repeated unknown reads; raw DB/WAL identity and a relaxed global fingerprint are not semantic proof.

Distinguish ledger-only membership from missing publication: a task can lack a direct chat link yet have a current owner publication. A retained ledger status plus fresh owner heartbeat does not prove that observation current. Require exact owner row/version/payload or conservatively return unknown; never call the writeful ledger projector inside capture.

Exercise real canonical projection as an independent disposable-store oracle for missing rows, version/content mismatch, terminal evidence and healthy observations. Hold a real `BEGIN IMMEDIATE` writer on the fixture ledger to prevent canonical refresh and expose retained-observation mismatches. Preserve all old assertions; repair a fixture's invalid healthy-source premise rather than relax expected behavior.

Evaluate decisive unknown fences before expensive complete-inventory decoding. Local-authority eligibility needs only the captured ledger; exact retained-owner mismatches can be checked by owner/key inside the same replica read transaction. Preserve the unknown verdict and no-notification recovery, and test source-open/query counts, not just digest correctness. A fast unknown capture does not prove remote memo reuse or production CPU acceptance.

Fence unavailable local authority instead of issuing reusable absence certificates. Compose ActionStore request/binding/operation and historical namespace dependencies in the consuming memo, not the remote membership API. Retain single-flight, deferred failure backoff and a non-sliding actual-full-pass ceiling. A standalone capture is not itself live latency proof: measure a fresh natural routed-serve window only after memo wiring lands, and report zero unchanged samples as missing proof.

Profile a known successful composed memo hit through `CoreReaders.reconcile_sources` and `panel_reconcile`, including local reconciliation and ActionStore stamp work, rather than timing only a membership helper. Complete inventory scans can spend seconds decoding unrelated task bodies. A bounded content-addressed decoder cache may retain compact identity/creation/scoped-link metadata only when every current publication is still read and hashed; never turn publication versions, global DB/WAL identity or cache age into semantic absence proof. Re-read selected full publications within the same transaction and preserve all unknown/freshness/owner fences. JSON byte parsing accepts a BOM and encoded lone surrogates that the original TEXT reader rejects. Test same-byte BLOB-to-TEXT transitions after warming the cache, plus repeated unknown results. Guard source work as well as CPU at production-sized payloads; use thread CPU to distinguish work from scheduling delays. Label replay clock alignment, fixed display projections and preseeded successful memos explicitly, and keep a concurrent real-capture CPU/GIL control separate from historical live-thread attribution.
