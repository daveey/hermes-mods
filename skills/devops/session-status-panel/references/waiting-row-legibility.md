If both are absent, trace the reader's status selection and wait-description handling; dependency wording can be reconstructed independently of timing metadata. Reproduce through the real reader→reducer path with the affected status, then compare an otherwise-identical input with a timestamp. Tests that inject `waiting_since` prove formatting, not that production supplies it. Persisted model evidence does not establish which revision is currently painted in native pixels.
