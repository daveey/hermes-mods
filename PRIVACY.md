# Privacy Policy — Hermes Agent (personal OAuth client)

The "Hermes Agent" Google OAuth client is a personal tool used by its owner to let a
self-hosted Hermes agent read and act on the owner's own Google account data (Gmail,
Calendar, Drive, Docs, Sheets, Contacts).

- **Who uses it:** only the owner. It is not offered to the public.
- **What data is accessed:** only the Google data the signed-in user grants on the consent
  screen, and only to perform tasks that user asks for.
- **Where data goes:** OAuth tokens and fetched data stay on the user's own machines. Nothing
  is sold, shared with third parties, or used for advertising.
- **Retention / revocation:** revoke access at any time at
  https://myaccount.google.com/permissions; locally stored tokens can be deleted by the user.
- **Google API Services User Data Policy:** use of data received from Google APIs adheres to
  the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
  including the Limited Use requirements.
Contact: the user support email shown on the Google consent screen.
